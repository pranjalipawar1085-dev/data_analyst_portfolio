CSAT Analytics Project

Project Overview:
This project focuses on analyzing customer satisfaction data to understand customer experiences and identify areas for improvement.

Dataset:
Total Records: 32,942
Total Columns: 12

Tools Used:
SQL,
Power BI

Project Objectives:
Analyze customer satisfaction scores.
Understand customer sentiment.
Identify common customer call reasons.
Analyze response times.
Find trends in customer service performance.

Key Analysis:
This project includes customer satisfaction analysis, call trends, sentiment analysis and response-time analysis.

Conclusion:
The analysis helps understand customer satisfaction and identify opportunities to improve customer service.
